# Каталог доноров

Написанное однажды не должно писаться дважды. Здесь ведётся таблица: что уже
сделано, в каком проекте лежит и с каким разбором. Файл нужен ровно затем, чтобы
третий по счёту переключатель вкладок не писался с нуля просто потому, что никто не
помнил про первые два.

## Правило

**Берётся вместе с разбором.** Модуль без своего ADR приезжает без причин, по которым
в нём стоят именно эти числа, и первая же правка их сотрёт.

**Разметка не берётся.** Переезжает механика; вёрстка пишется заново по своему
макету. Именно поэтому модули цепляются за `data-*`, а не за классы.

**Токены не берутся.** Числа цвета и типографики снимаются со своего макета: чужая
палитра, приехавшая «на первое время», остаётся навсегда.

## Что можно забрать отсюда

| Что нужно                                | Модуль                               | Разбор                                |
| ---------------------------------------- | ------------------------------------ | ------------------------------------- |
| маска телефона `+7`                      | `src/scripts/phone-mask.ts`          | `0003-phone-mask-and-form-validation` |
| модалки с Esc и возвратом фокуса         | `src/scripts/modal.ts`               | `0003-…` (раздел про тряску)          |
| словарь в `localStorage`                 | `src/scripts/store.ts`, `storage.ts` | `0008-client-state`                   |
| корзина и сравнение                      | `src/scripts/cart.ts`, `compare.ts`  | `0008-client-state`                   |
| фильтр-сортировка-пагинация в адресе     | `src/scripts/catalog.ts`             | `0007-catalog-state-in-the-url`       |
| вкладки с якорем в хеше                  | `src/scripts/tabs.ts`                | —                                     |
| слайдер на точках                        | `src/scripts/slider.ts`              | —                                     |
| примитивы движения без зависимостей      | `src/scripts/motion.ts`              | `0009-ordered-motion`                 |
| сцена фильтрации: призраки, FLIP, шторка | `src/scripts/scene.ts`               | `0009-ordered-motion`                 |
| полёт товара в корзину                   | `src/scripts/fly.ts`                 | `0009-ordered-motion`                 |

Вкладки и слайдер стоят без разбора не случайно: модули по десять строк, и
объяснять в них нечего. Правило «берётся вместе с разбором» на них не
распространяется ровно потому, что причин, которые можно стереть правкой, там нет.

`motion.ts` переносится первым: от него зависят и `scene.ts`, и `fly.ts`, и
прочерк засечек. Брать `scene.ts` без разбора особенно не стоит — там числа трёх
механизмов, разведённых по времени, и любое из них само по себе выглядит
произвольным.

## Как добавлять строку

Строка появляется, когда что-то **понадобилось второй раз**. Не «может
пригодиться»: каталог полезен ровно тем, что его читают целиком, а список из
полусотни «может быть» не читают вовсе.
