# DEVICE

Интернет-магазин гаджетов на Astro. Перенос готовой статической вёрстки из
`../device` — пиксель в пиксель, с рабочей логикой поверх.

Проект **собирается, проходит линт, типы и браузерные тесты сразу после
`yarn install`.** Если что-то из этого падает — чинить надо проект, а не обходить.

## Что перенесено и что придумано

Из исходника приехали две страницы — главная и каталог моноподов, — три модалки,
шапка, подвал и весь CSS. Это перенос: числа, тексты и порядок блоков сохранены,
сверка — снимками одинаковой высоты.

Исходник при этом ссылался на семь несуществующих страниц. Все семь свёрстаны
заново в его же языке — те же гарнитуры, та же жёлтая полоса под кнопкой, те же
чёрные засечки 80×7 над колонками:

| Адрес                | Что это                                          |
| -------------------- | ------------------------------------------------ |
| `/catalog`           | шесть разделов плитками со счётчиком товаров     |
| `/catalog/[раздел]`  | выдача раздела: фильтр, сортировка, пагинация    |
| `/product/[товар]`   | карточка: цена, кнопки, описание, характеристики |
| `/cart`              | корзина: количество, сумма, оформление           |
| `/compare`           | сравнение до четырёх товаров таблицей            |
| `/profile`           | данные покупателя и история заказов              |
| `/login` и `/logout` | вход страницей и выход                           |

За ними потянулись ещё пять адресов, на которые ссылался уже сам перенос:

| Адрес          | Что это                                        |
| -------------- | ---------------------------------------------- |
| `/search`      | поиск по названиям и описаниям всех товаров    |
| `/about`       | о магазине: с какого года, кто собирает заказы |
| `/brand/[имя]` | производитель и раздел, где лежат такие товары |
| `/restore`     | восстановление пароля из формы входа           |
| `/404`         | страница не найдена                            |

Всего 59 страниц: главная, каталог и шесть разделов, 38 карточек товаров,
четыре производителя и девять служебных.

## Что работает по-настоящему

- **Фильтр и сортировка.** Диапазон цены тянется мышью и клавиатурой, цвета
  складываются по «или», Bluetooth — три состояния. Сортировка по цене, типу и
  популярности в обе стороны. Всё состояние — в адресе, ссылкой делятся.
- **Корзина и сравнение.** `localStorage`, счётчики в шапке и подвале, пересчёт
  суммы, пустые состояния. Оформление складывает заказ в историю.
- **Вход.** Имя запоминается, шапка меняется, кабинет открывается. Пароль не
  проверяется: сервера нет.
- **Модалки.** Вход, письмо и карта — с валидацией, тряской пустой формы, закрытием
  по Esc и затемнению, возвратом фокуса.
- **Слайдер и вкладки сервисов.** Вкладка открывается ещё и якорем из шапки.
- **Движение.** Товар улетает в корзину дугой, счётчик отзывается, выдача каталога
  пересобирается сценой из трёх механизмов — ушедшее гаснет призраком, оставшееся
  переезжает, пришедшее открывается шторкой. Слои слайдера расходятся, засечки
  прочерчиваются, сумма в корзине набегает счётом. Всё гаснет под
  `prefers-reduced-motion` и не двигает раскладку в покое.

Всё это покрыто 49 браузерными тестами.

## Команды

```
yarn dev            # дев-сервер на 4321
yarn build          # astro check && astro build
yarn preview        # просмотр сборки
yarn lint           # ESLint
yarn lint:styles    # Stylelint
yarn format         # Prettier
yarn test:browser   # Playwright: собирает и поднимает просмотр на 4331
```

**Только Yarn.** `npm install` при наличии `yarn.lock` перепишет его под себя и
сломает установку у коллег на других платформах — разбор в `CLAUDE.md`.

## Сверка с исходником

```
cd ../device && npx http-server -p 4399 -s
npx playwright screenshot --viewport-size="1440,900" http://localhost:4399/index.html original.png
```

Главная и каталог сходятся полной высотой страницы: 2830px и 2035px. Сверка не на
глаз: скрипт-разность считает несовпавшие точки попиксельно — порядок в
`docs/tests.md`.

На одном и том же слайде главная расходится с оригиналом на 12961 точку из
четырёх миллионов, и всё это — исправленные дефекты исходника: кружки
переключателей и число слайда с белой засечкой, которые исходник срезал своим
`overflow: hidden`. Плюс подвал: знак школы из него убран, на его месте —
копирайт магазина.
