# Личный кабинет: заказы с сервера

Status: ready-for-agent
PRD: .scratch/backend/PRD.md

Кабинет перестаёт читать `localStorage` и берёт заказы у сервера — только свои.
У каждого заказа: номер, дата, состав со снимками цен, сумма и состояние.

Состояний четыре: новый, в работе, выполнен, отменён. **Пока заказ новый,
покупатель может отменить его сам** — кнопкой в кабинете. Дальше отменяет только
продавец.

Имя покупателя берётся из аккаунта. E-mail и телефон пока остаются подсказками в
браузере: эндпоинта правки профиля нет, поле `users.phone` заполняется только из
заказа. Это осознанный долг, а не оплошность — правка профиля будет вместе с
админкой.

## Приёмка

- Чужой заказ не открывается по прямой ссылке — 404, а не 403 с подтверждением
  существования.
- Отмена работает только для нового заказа; для остальных кнопки нет и запрос
  отклоняется.
- Гостевой заказ в кабинете не появляется, даже если телефон совпал.

## Comments

**Сделано.** Кабинет читает заказы у сервера.

`GET /api/orders` отдаёт последние двадцать заказов вошедшего — и только его:
гостю 401, чужой заказ не показывается и не отменяется (404, а не 403, чтобы по
ответу нельзя было проверить существование чужого номера).

В кабинете у заказа появились номер, состояние словами («Новый», «В работе»,
«Выполнен», «Отменён») и кнопка отмены. Кнопка видна только у нового заказа;
`POST /api/orders/:number/cancel` для остальных отвечает 422.

Локальная история из `localStorage` больше не читается — модуль `orders.ts`
удалён.

Проверено: четыре интеграционных теста (свои заказы, отмена нового, чужой заказ,
заказ в работе) и браузерная спека с отменой из кабинета.
