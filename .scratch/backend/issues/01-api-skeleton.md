# Каркас device-api

Status: ready-for-agent
PRD: .scratch/backend/PRD.md

Отдельный репозиторий `device-api`: Express 5 на TypeScript в strict-режиме,
Yarn 1.22 classic (правило про запрет `npm install` переезжает вместе с
проектом), ESLint и Prettier с теми же настройками, что во фронте.

Внутри: чтение конфигурации из окружения с проверкой при старте, структурные
логи, обработчик ошибок, отдающий один формат ответа на все отказы, и
`GET /api/health`. Бизнес-логики на этом шаге нет.

`docker-compose.yml` поднимает Postgres и сам API.

## Приёмка

- `yarn dev` поднимает сервер, `GET /api/health` отвечает 200.
- Запуск без обязательной переменной окружения падает сразу и с внятным текстом,
  а не на первом запросе.
- Необработанное исключение в обработчике даёт 500 в общем формате ошибки, а не
  стек в теле ответа.

## Comments

**Сделано.** Репозиторий `../device-api`, рядом с фронтом и исходником.

Состав: Express 5 на TypeScript 6 (strict плюс `noUncheckedIndexedAccess`,
`exactOptionalPropertyTypes`, `erasableSyntaxOnly`), ESM с `nodenext`, `tsx` для
разработки и `tsc` для сборки. Логи — `pino` с `pino-http`. Окружение читается
схемой zod один раз при старте, тексты жалоб на русском. Линтер, Prettier и хуки
husky повторяют фронт; из конфига ESLint убраны astro и jsx-a11y, добавлен
`allowDefaultProject` для `lint-staged.config.mts` — он лежит вне `tsconfig`.

Проверено:

- `GET /api/health` — 200 `{"status":"ok","uptime":0}`
- неизвестный адрес — 404 в общем формате ошибки
- тело не-JSON — 400 в том же формате
- необработанное **асинхронное** исключение — 500 общей фразой, стек только в
  логе
- запуск без `DATABASE_URL` — падение до открытия порта, код выхода 1, текст
  «переменная не задана» плюс отсылка к `.env.example`
- `yarn build`, `yarn lint`, `yarn typecheck`, `yarn format:check` — чисто

**Не проверено:** `docker compose up`. Docker Desktop на машине не запущен,
движок не отвечает; `docker compose config` синтаксис принимает. Первый реальный
запуск контейнеров — вместе с задачей 02, там база и нужна.

**Отклонение от задачи:** TypeScript взят версии 6, а не 7. На 7.0
`typescript-eslint` отказывается работать («does not support TS 7.0»), а линт
дороже свежести компилятора. Фронт тоже на 6.

`git init` сделан, коммитов нет: коммит — по просьбе.
