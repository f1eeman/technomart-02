# Проверки второго этапа

Status: ready-for-agent
PRD: .scratch/backend/PRD.md

**В API** — интеграционные тесты по тестовой базе: жизнь корзины, слияние при
входе, оформление с пересчётом, отказ при изменившейся цене, двойная отправка,
регистрация и вход, сброс пароля, права на чужой заказ.

**Во фронте** — браузерные спеки на моке: корзина переживает перезагрузку, вход
складывает корзины, модалка оформления требует имя и телефон, кабинет показывает
заказ и отменяет новый. Мок каталога дополняется корзиной, заказами и входом.

## Приёмка

- `yarn test` в API проходит на чистой базе и сносит её за собой.
- `yarn test:browser` во фронте по-прежнему не требует ни Postgres, ни API.
- Ни один спек не ходит в настоящую почту: письма проверяются через ловушку.

## Comments

**Сделано** — по ходу задач 10–15, а не отдельным заходом.

В API 45 интеграционных тестов на своей базе: выдача и поиск (с первого этапа),
корзина и её чистка, аккаунты со слиянием корзин, оформление с пересчётом и
двойной отправкой, свои и чужие заказы, сброс пароля.

Во фронте 69 браузерных спек на моке: он научился держать корзину по cookie,
регистрацию, вход, выход, заказы, отмену и сброс пароля. Живой API и Postgres
по-прежнему не нужны, прогон — около сорока секунд.

Ни один спек не ходит в настоящую почту: мок отвечает на запрос ссылки 204, а
годным считает единственным годным токен `mock-token`.

**Две вещи, которые пришлось поправить в самой обвязке.** Мок выдавал
предсказуемые ключи сессий — параллельные воркеры перетирали друг другу вход;
теперь ключ случайный. И тестов в API стало больше восьми, из-за чего линт
перестал справляться «дефолтным проектом» — тестам выдан собственный tsconfig.
